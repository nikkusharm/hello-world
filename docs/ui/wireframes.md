# Phase 1 UI Wireframes

## Admin Shell

- Left navigation: Dashboard, Users, Projects, Roles, Audit Logs, Settings.
- Header: environment badge, search, notifications, user menu.
- Main panel: module-specific card layout with filters and export actions.

## Users

- Table columns: name, email, role, department, status, last login, actions.
- Create dialog: display name, email, role, department, project/customer permissions.

## Projects

- Table columns: project code, name, customer, owner, status, release readiness placeholder.
- Detail page tabs: Overview, Members, CAD Files, Rules, Reviews, Audit.

## Audit Logs

- Filter bar: date range, actor, action, entity type, project, customer.
- Log table: timestamp, actor, action, entity, details, correlation id.
